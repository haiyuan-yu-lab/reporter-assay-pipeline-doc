# CLI overview

The package installs three console commands:

| Command | Role |
| --- | --- |
| [`yulab_reporter_pipe`](pipe.md) | Nine pipeline steps plus grouped workflows |
| [`yulab_reporter_qc`](qc.md) | Read-only analytical / QC plots |
| [`yulab_reporter_export`](export.md) | ExogeneousSequences export |

Detailed flag pages will expand over time. For now, use `--help` on each
command.
